## 🎓 Key Concepts to Understand

### Multi-Step Wizard Pattern
A user interface pattern that breaks a complex process into simple steps.

**Key Benefits**:
- Reduces cognitive load
- Prevents errors
- Guides users through workflow
- Professional appearance

**In Our Case**:
- 8 steps for creating orders
- Validation at each step
- Can go back to edit
- Review before submit

### Pinia Store
Vue 3 state management library used for centralized order data.

**Key Features**:
- Single source of truth
- Type-safe (TypeScript)
- Actions for API calls
- Computed getters

**In Our Case**:
- Stores orders list
- Manages dropdowns (types, statuses, currencies)
- Handles create/update/delete operations

### Component-Based Architecture
Breaking UI into reusable, self-contained components.

**In Our Case**:
- OrderWizard: Main wizard (850 lines)
- OrderList: List view
- OrderForm: Edit view
- OrderDetails: Detail view
- All work together

### Reactive Data in Vue 3
Automatic UI updates when data changes.

**In Our Case**:
- wizardData reactive object
- Computed properties for calculations
- Form fields update data automatically
- Progress bar updates in real-time
