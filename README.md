## 🧠 Type Support for `.vue` in TypeScript

TypeScript doesn't handle `.vue` files by default. To fix this:

- Use `vue-tsc` instead of `tsc`
- Use Volar plugin for proper type support

### 👉 Enable Take Over Mode for Better Performance

1. Open VSCode Command Palette → `Extensions: Show Built-in Extensions`
2. Find **TypeScript and JavaScript Language Features**
3. Right click → **Disable (Workspace)**
4. Reload window: `Developer: Reload Window`
